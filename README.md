# 8 Ball Pool — Бильярд

Браузерная игра в восьмёрку в стиле **8 Ball Pool** с полу-3D графикой, физикой шаров и ИИ-соперником.

## Запуск

```bash
python3 -m http.server 8080
```

Откройте http://localhost:8080 или `index.html` на телефоне.

## Возможности

- Полу-3D шары с бликами, тенями и полосатыми номерами
- Стол высокого разрешения (1600×880) с текстурой сукна и дерева
- Линия прицела с предсказанием удара и отскоков
- Анимация забирания шаров в лузу
- ИИ-соперник с прицеливанием и выбором ударов
- Правила 8-ball: разбой, группы, фолы, свободный биток

## Управление

- Двигайте палец/мышь для прицеливания
- Потяните назад от битка и отпустите для удара
- После фола — тап для постановки битка
