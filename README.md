# Інтерактивна карта України (DeepState-стиль, населення 2026)

Карта України у стилі DeepState: області → райони → громади (аж до рівня громад, що охоплюють усі села).
Клік по регіону показує орієнтовне населення на 2026 рік.

## Запуск

```bash
npm install
npm start
```

Відкрити http://localhost:3000

## Що всередині

- **Leaflet** (локально, без CDN) + сірі тайли Esri
- **Межі:** `regiony.geojson` (26 областей), `rayony.geojson` (136 районів), `hromady.geojson` (1472 громади) — джерело: ukrainian_geodata (АТУ 2020)
- **Стилізація DeepState:** червоний — окуповано РФ, помаранчевий — зона бойових дій, зелений — під контролем України
- **Населення 2026** — оцінка: `pop2021 * factor` (війна, біженці, мобілізація). Для районів/громад — розподіл пропорційно площі області
- **Міста** — кружечки з населенням (Київ, Харків, Одеса, Дніпро, Львів тощо)

## Примітки

Населення — **оцінка**, не точні дані. Громада = територіальна громада (об'єднання сіл/міст), тому рівень покриває всі населені пункти України.
