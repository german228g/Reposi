# 8 Ball Pool — Бильярд

Браузерная игра в восьмёрку с полу-3D графикой и ИИ-соперником.

## 🎱 Открыть на iPhone за один тап

### Онлайн (после публикации)

**https://german228g.github.io/Reposi/**

> Если ссылка не открывается — один раз включите Pages:  
> GitHub → Settings → Pages → Source: **GitHub Actions**  
> Подробнее: [PUBLISH.md](PUBLISH.md)

### Локально (Mac/PC + iPhone в одном Wi‑Fi)

```bash
chmod +x serve-ios.sh && ./serve-ios.sh
```

Откройте напечатанный адрес в **Safari** на iPhone.

### Иконка на экране (запуск в 1 тап)

1. Откройте игру в **Safari**
2. **Поделиться** ⬆️ → **«На экран Домой»**
3. Готово — как обычное приложение!

## Локальный запуск

```bash
python3 -m http.server 8080
```

Откройте http://localhost:8080

## Возможности

- Полу-3D шары и стол высокого разрешения
- Линия прицела с предсказанием удара
- ИИ-соперник
- PWA — работает офлайн после первого открытия
- Оптимизация под iPhone (touch, fullscreen)
