# 8 Ball Pool — Бильярд

Браузерная игра в восьмёрку с полу-3D графикой и ИИ-соперником.

## 🎱 Открыть на iPhone за один тап

### Вариант 1 — Ссылка (сразу играть)

**https://german228g.github.io/Reposi/**

Откройте в Safari → нажмите **▶ ИГРАТЬ**

### Вариант 2 — Иконка на экране (как приложение)

1. Откройте ссылку выше в **Safari**
2. Нажмите **Поделиться** ⬆️
3. Выберите **«На экран Домой»**
4. Готово — запуск **в один тап** с рабочего стола!

## Локальный запуск

```bash
python3 -m http.server 8080
```

Откройте http://localhost:8080

## Возможности

- Полу-3D шары и стол высокого разрешения
- Линия прицела с предсказанием удара
- ИИ-соперник
- PWA — работает офлайн после первого открытия
- Оптимизация под iPhone (touch, fullscreen)
