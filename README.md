# 8 Ball Pool — Бильярд

## 📱 Открыть на iPhone (без Mac, только телефон)

### Скопируйте и откройте в Safari:

# 👉 https://tinyurl.com/28ww5thg

1. Откройте **Safari**
2. Вставьте ссылку в адресную строку
3. Нажмите **▶ ИГРАТЬ**
4. Чтобы играть в 1 тап: **Поделиться** → **«На экран Домой»**

Подробная инструкция: [IPHONE.md](IPHONE.md)

## Возможности

- Полу-3D шары и стол
- Линия прицела, ИИ-соперник
