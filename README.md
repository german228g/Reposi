# OFFICIALBRAND Receipt Bot

Telegram-бот для генерации чеков OFFICIALBRAND.

## Установка

```bash
pip install -r requirements.txt
python3 main.py
```

## Сценарий

1. `/start`
2. Фото продукта
3. Название продукта
4. Имя покупателя
5. Email

Бот пришлёт PNG в Telegram и отправит письмо с чеком в теле (`cid:receipt`).
