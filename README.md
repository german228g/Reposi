# 8 Ball Pool — Бильярд

Браузерная игра в восьмёрку в стиле **8 Ball Pool**: физика шаров, кий с оттяжкой, лузы и правила.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8080
```

Затем откройте http://localhost:8080

## Управление

- **Прицел** — наведите курсор на биток
- **Удар** — потяните кий назад от битка и отпустите (чем дальше, тем сильнее)
- **Свободный биток** — кликните на стол после фола
- **Новая игра** — кнопка внизу

## Правила

- Разбейте пирамиду первым ударом
- После забития шара определяется группа: цельные (1–7) или полосатые (9–15)
- Забейте все свои шары, затем восьмёрку
- Фол: биток в лузу, промах, забит чужой шар

## Структура

- `js/physics.js` — векторы, столкновения, трение
- `js/balls.js` — шары и расстановка пирамиды
- `js/table.js` — стол, борта, лузы
- `js/cue.js` — кий и линия прицела
- `js/game.js` — правила и состояние игры
- `js/main.js` — игровой цикл
