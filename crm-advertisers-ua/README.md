# 100 кандидатов для рекламы CRM (Украина)

Список собран под **украинский CRM-проект**: агентства, таргетологи, Telegram/Instagram специалисты, медиа и площадки, где можно быстро найти исполнителей для **тестовой рекламы**.

Файл списка: [`candidates-100.csv`](./candidates-100.csv)

## Что внутри

| Приоритет | Кого брать первыми |
|-----------|-------------------|
| **A** | Telegram Ads реселлеры, performance-агентства, сильные фрилансеры, биржи, UA бизнес-медиа |
| **B** | Остальной топ Ringostat, media-агентства, региональные пулы |
| **C** | Креатив / PR / доп. директории |

Колонка `outreach_status`: меняйте `todo` → `sent` → `replied` → `test` / `rejected`.

## Важно про «отправку»

Из этой среды **нельзя** массово написать в Telegram/Instagram от вашего имени (нет доступа к вашим аккаунтам).  
Готовый список + тексты ниже — копируете и рассылаете сами (или через помощника).

Рекомендуемый порядок:
1. Открыть 15–20 строк с `priority=A`
2. Отправить короткий бриф (шаблон ниже)
3. Тем, кто ответил — дать тест-бюджет на 3–7 дней
4. Масштабировать 2–3 лучших

## Шаблон сообщения (русский)

```
Привет! Ищу подрядчика на тест рекламы украинского CRM.

Гео: Украина
Язык креативов: украинский (+ русский при необходимости)
Каналы: Telegram / Instagram / Meta — что лучше зайдёт под B2B CRM
Задача: тестовый запуск на лиды (демо / заявка), не «просто охваты»
Формат: короткий тест 3–7 дней, понятный CPL/стоимость заявки, потом масштабирование

Если берёте такие тесты — напишите:
1) опыт с SaaS/CRM или B2B
2) какие каналы предлагаете на старт
3) минимальный бюджет теста + ваша комиссия/фикс
4) 1–2 кейса с цифрами

Спасибо!
```

Гео: Україна
Мова креативів: українська
Канали: Telegram / Instagram / Meta — що краще зайде під B2B CRM

Формат: короткий тест 3–7 днів, зрозумілий CPL, далі масштабування

Якщо берете такі тести — напишіть:
1) досвід із SaaS/CRM або B2B
2) які канали пропонуєте на старт
3) мінімальний бюджет тесту + ваша комісія/фікс
4) 1–2 кейси з цифрами

Дякую!

## Бриф для агентства (короткий)

- Продукт: CRM для украинского рынка
- ЦА: владельцы бизнеса / отделы продаж / SMB-SME UA
- Цель теста: заявки на демо / регистрацию
- Бюджет теста: [укажите сумму]
- KPI: CPL / стоимость квалифицированной заявки
- Срок: 3–7 дней тест → решение о продолжении
- Материалы: лендинг, оффер, пиксель/аналитика, CRM для лидов
