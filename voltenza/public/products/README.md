# Фотографии товаров

Положите сюда реальные фотографии товаров с именами файлов, указанными в
поле `image` каждого товара в `src/data/products.ts`, например:

```
public/products/topk-magnetic-vent-mount.jpg
public/products/magcharge-disc.jpg
```

Пока файл отсутствует, карточка товара показывает минималистичную
SVG-заглушку в фирменном стиле — сайт продолжает работать без ошибок.

Рекомендации:
- квадратные фото (1:1), минимум 1200×1200px;
- формат `.jpg` или `.webp`, сжатые (< 300 КБ) для быстрой загрузки;
- нейтральный/белый/бежевый фон в духе минимализма бренда.
